模型服务

⚡ Chrome 内置 AI（Gemini Nano）

当前浏览器尚未提供可用的内置模型接口。支持情况取决于 Chrome 版本、设备条件和模型下载状态。可以重新检测，或改用 TT Switch。

TT Switch 会将标签标题和脱敏网址转发给所选模型服务；本机代理不等于离线推理。
API Token 填 TT Switch → 通用 API → 腾讯内网通用服务的 API Token。标题和网址会经 TT Switch 发给所选模型。密钥以本地明文存储，不通过 Chrome 同步。网址参数、片段和账号密码不会发送；标题和路径仍可能包含敏感内容。
🛡️

隐私与数据发送

仅发送待整理标签的标题和脱敏网址（域名、路径）。不发送网址账号密码、查询参数、片段或历史学习记录。复用分组时会发送含可参与整理标签的现有分组名称。标题和路径仍可能包含敏感信息，请将工作内网站点加入排除列表。

排除内网地址

忽略私有 IPv4、IPv6 地址、localhost、单标签主机名及 .local / .internal 等地址。不查询 DNS；公司公网域名需手动排除。

每行一个域名，同时匹配其子域名；也支持逗号分隔。排除仅约束 AI，本地手动分组和规则仍可使用。全部设置和规则仅保存在本机。
